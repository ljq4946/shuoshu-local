# 说书人 · 使用说明

把 TXT 书稿和一段参考录音导入本机，制作指定音色的中文有声书，按章导出 WAV 和 MP3。

当前使用 **IndexTTS 2.5 原始模型**，`tts_adapter` 为空，不加载训练后的 LoRA。每本书的音色由参考录音决定。语音校对使用 SenseVoiceSmall 与 FSMN-VAD，制作过程在本地完成。

## 1. 开始制作

本机运行环境已经准备好。日常使用直接双击项目根目录的 **start.cmd**。

1. 选择“导入新书，检查章节并试读”，依次选择 TXT 书稿和参考录音。
2. 在打开的制作面板里检查章节目录，必要时用原稿起始行或标题规则调整，再确认目录。
3. 播放参考声音，按需调整截取起点；生成试读，听完后确认音色。
4. 点击“开始 / 继续制作”。合成、校对和异常重试会自动进行，可以随时暂停。
5. 复听待确认片段，选择接受或仅重做该段，再继续制作并下载章节成品。

保持启动窗口开启。面板地址为本机 `http://127.0.0.1:端口`，端口由程序分配。关闭窗口或按 Ctrl+C 后，重新启动并选择“继续上一次制作”即可恢复。也可以选择已有书籍目录，或打开该目录下的 `review.html` 离线复听。

参考录音须为清晰单人讲话，至少 **3 秒**，建议 10–15 秒。程序从选定起点取最多 15 秒，转换为固定的参考 WAV，并另存原始录音。参考声音明显不理想时，先更换录音重新试读。

## 2. 命令行使用

在项目目录打开 PowerShell。下面使用自己的 TXT 书稿和项目内一段约 6 秒的参考录音：

```powershell
Set-Location 'D:\work\demo\说书人'

.\run.ps1 init 'D:\书稿\小说.txt' --voice '.\01_语音\SR010464.wav' --out '.\books\我的有声书'
.\run.ps1 studio '.\books\我的有声书'
```

把书稿和录音路径换成自己的文件。每本新书使用一个新的、空的输出目录；同一本书续跑时使用原目录。

完全使用命令行时，导入后依次运行：

```powershell
.\run.ps1 preview '.\books\我的有声书'
# 播放 books/我的有声书/preview/voice.wav，检查目录并实际试听。
.\run.ps1 confirm '.\books\我的有声书' --chapters --voice --note '已检查目录并试听'
.\run.ps1 run '.\books\我的有声书'
```

`confirm` 用于保存你已经完成的检查。新书必须确认目录和试读后才能开始全书制作。试读中已通过的片段会用于正式制作。

### 常用操作

| 操作 | 命令示例 |
|---|---|
| 打开制作面板 | `.\run.ps1 studio '.\books\我的有声书'` |
| 继续制作 | `.\run.ps1 run '.\books\我的有声书'` |
| 查看已保存的进度 | `.\run.ps1 status '.\books\我的有声书'` |
| 更新离线复听报告 | `.\run.ps1 report '.\books\我的有声书'` |
| 仅重做一个片段 | `.\run.ps1 retry '.\books\我的有声书' c0001_s0002` |
| 试听后接受识别误报 | `.\run.ps1 approve '.\books\我的有声书' c0001_s0002 --note '已复听，音频正确'` |
| 指定章节起始行 | `.\run.ps1 plan '.\books\我的有声书' --starts '1,18,42'` |

`retry`、`approve` 或修改读音表后，再运行 `run` 完成剩余处理。章节起始行从 1 开始，只能在正式制作前重划章节。`status` 可以在制作期间使用；`report` 会写入报告，应在制作暂停或结束后使用。

## 3. 书稿与读音

TXT 默认尝试 UTF-8 和 GB18030；其他编码在 `init` 时用 `--encoding` 指定。标题会朗读，开篇文字会保留。书稿不会被大模型改写；`***` 等纯标点分隔行作为场景停顿保留。

自动分章不适合书稿时，可以在面板调整，或导入时增加 `--chapter-pattern '章节标题的整行正则'`。从参考录音第 5 秒开始截取，可在 `init` 中增加 `--reference-start 5`。

自动分章支持“第一章雨夜”“第一卷风起”等紧连标题。“回、节、部、集、篇”后须有空格、冒号等标题分隔，避免把“第一回见面时……”等正文分成新章。无分隔的章回体标题可用自定义规则，例如 `--chapter-pattern '第[一二三四五六七八九十百零〇两0-9]+回.*'`，或在面板指定起始行。

人名、地名、多音字读错时，在面板编辑读音词典，或修改书籍目录里的 `pronunciations.json`：

```json
{
  "重庆": "<重|CHONG2>庆",
  "单明": "<单|SHAN4>明",
  "银行": "银<行|HANG2>"
}
```

规则只标注原字的读法。程序按最长词条匹配，并保护数字、时间和读音标注的完整边界。继续制作时，只会重做受读音规则影响的片段。

## 4. 设置

当前本机配置 `config.local.json` 显式设置 `"tts_adapter": ""`，使用原模型。其他设置沿用代码默认值，常用配置示例见 [config.example.json](config.example.json)。需要调整时，将相关项目添加到 `config.local.json`。

| 设置 | 默认值与含义 |
|---|---|
| `tts_adapter` | 空字符串，使用原始模型 |
| `device` / `bf16` | `cuda:0` / `true`，使用显卡和 BF16 |
| `speed` | `1.0`；范围 0.5–2.0，大于 1 放慢，小于 1 加快 |
| `max_chars` | 每段约 180 字；数字、词条和发音标注可能使片段略长 |
| `gap_ms` | 普通片段间停顿 180 毫秒 |
| `inference_gap_ms` | 片段内部生成停顿，导入时随书固定；默认自动沿用 `sentence` 模式的初始 `gap_ms`，`legacy` 模式为 200 毫秒。新书可显式设为 0–3000；`null` 表示自动 |
| `scene_gap_ms` | 场景停顿 800 毫秒，替代该处普通停顿 |
| `max_retries` | 固定为 2，即每段最多自动合成 3 次 |
| `stage_timeout_seconds` | 无进度超时 7200 秒，有持续进度的长任务可继续 |
| `qa.max_cer` | 转写文字差异率阈值 0.08，另检查连续漏读、关键数值和音频时长 |
| `export` | WAV 为 PCM16 单声道，MP3 默认 128 kbps，响度目标 -19 LUFS |

新书会保存本书的配置。后续续跑优先恢复书籍设置，修改全局配置不会自动更改已保存的书籍。显式指定配置文件时，`--config` 放在子命令前：

```powershell
.\run.ps1 --config '.\config.local.json' status '.\books\我的有声书'
```

正式制作后，参考声音、模型、精度和语速保持固定；片段内部生成停顿从导入起固定。更换这些固定的生成设置请新建书籍项目。界面中的普通段间停顿、场景停顿及导出设置只影响拼接与导出，可以继续复用有效语音。读音词典也可以调整，受影响的旧成品会归档，再按需重新导出或合成。

校对会区分数字范围、分数、数字列表及正负号，并兼容“三到五”“二分之一”等等价读法。可通过 `qa.critical_terms` 配置重点核对的词语；大小写、全角字符和中文数字会按正文的相同规则处理。规范化后为空或重复的关键字配置会报错。校对规则升级后，续跑会重新校对旧的机器通过片段，复用已有语音；人工确认的片段保留原确认。

## 5. 文件与成品

每本书保存在独立目录：

```text
books/书名/
├─ input/                 书稿副本、原始录音、固定的参考 WAV
├─ pronunciations.json    本书读音词典
├─ project.json           章节、片段、配置、处理进度和历史
├─ preview/voice.wav      开篇试读
├─ audio/                 各片段每次尝试的音频
├─ exports/               按章输出的 WAV 和 MP3
│  └─ history/            已失效的历史成品
├─ logs/                  模型加载、合成和识别日志
├─ review.html            可播放的离线复听报告
├─ review.csv             片段状态与异常清单
├─ summary.json           汇总进度和生产指标
└─ listening.json         保存后生成的人工听感记录
```

整章片段均通过机器校对或人工确认后，才会导出该章。中断后继续运行会复用有效音频；缺失或被改动的章节成品会按 SHA-256 检查结果重新导出。不要手动改动 `project.json` 或替换书籍中的参考 WAV。

自动识别可能误报同音字，也可能漏掉真实错读。先试听一章，再扩大到全书制作。面板支持保存听感记录；至少导出并实际试听 10 分钟、完成全部听评项，才会记录为人工验收通过。

## 6. 环境准备与排错

Git 仓库包含源码、脚本、测试、配置示例和文档；模型、运行环境、录音、训练数据与权重、书籍成品及本机配置不随仓库上传。新克隆、换机器或缺少依赖时，在项目根目录联网运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -Models
.\run.ps1 doctor --verify-hashes --load-models
```

环境和模型存入 `.runtime`、`.tools`。安装需要网络；安装完成后的合成和识别工作进程设置为离线模式，并阻止 Python 网络连接。`setup.ps1 -CoreOnly` 只准备控制端与 FFmpeg。

`doctor` 检查必要文件；`--verify-hashes` 校验模型内容；`--load-models` 依次真实加载 TTS 与 ASR，并在检查后退出进程释放显存。

| 遇到的问题 | 处理方法 |
|---|---|
| 提示章节或音色未确认 | 在面板完成目录检查和试读确认，或按第 2 节操作 |
| 提示参考录音不足或静音 | 调整截取起点，选择至少 3 秒的有效讲话 |
| 某段仍有异常 | 试听后接受，或仅重做该段，再继续制作 |
| 校对进程失败 | 查看 `logs/check-*.log`，修复环境后继续；已生成音频会保留 |
| 模型、参考声音或生成配置不一致 | 恢复原设置，或新建书籍项目 |
| 提示任务正在占用项目或显卡 | 暂停其他制作任务后重试 |

命令退出码：`0` 成功，`1` 输入、环境或执行错误，`2` 仍有片段待复听，`130` 用户中断。

训练数据和权重保存在 `training/`，详见 [训练目录说明](training/README.md)。当前制作入口使用原模型。
